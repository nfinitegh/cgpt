# User & Admin Documentation

## Consumer Mobile App
### Registration & Login
1. Sign up with email/phone.
2. Verify OTP.
3. Add vehicle plate number.

### Booking & Entry
1. Select location and entry time.
2. Choose duration and payment method.
3. Receive QR pass for entry.
4. Scan QR at kiosk or LPR auto-detects plate.

### In-App Payments
- Pay before exit with QRPH/GCash/Card.
- View receipts under History.

### Notifications
- Entry confirmation
- Expiry/overstay alerts
- Exit confirmation

## Cashier Operations
### Start of Shift
- Log in with cashier role.
- Verify device status (printer, scanner).

### Manual Entry
- Enter plate, vehicle type, zone.
- Issue session and print ticket.

### Payment Handling
- Search session by plate or code.
- Apply discounts or validations.
- Collect payment and print receipt.

### Lost Ticket
- Open lost ticket workflow.
- Verify plate and apply penalty.

### End of Shift
- X-reading for interim totals.
- Z-reading for final totals.
- Reconcile cash drawer.

## Admin Dashboard
### Site Management
- Create parking sites, zones, and capacities.
- Configure devices and assign to sites.

### Rate Rules
- Define flat/hourly/overnight rates.
- Configure grace periods and maximums.

### Reporting
- Revenue by site and date range.
- Occupancy heatmaps and peak hours.

### Security
- RBAC for admins, managers, cashiers.
- Audit logs for sensitive actions.
